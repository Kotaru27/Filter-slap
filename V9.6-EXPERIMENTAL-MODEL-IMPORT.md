# Filter Slap V9.6 — optional local ONNX (engineering test, not quality release)

The current app keeps the **V9.3 editor** as the default, all old features unchanged.

V9.6 adds an **optional local model import** so a user holding appropriately licensed model weights can test a truly offline learned-photo editor. This APK intentionally bundles **NO FiveK-trained model** and does not download one. Without import, it makes the **same V9.3 edits**. The user should not assume V9.6 improves their existing photos automatically.

## How to test

1. Open a photograph as usual, then tap **AI model** in the top bar.
2. Select **Choose local model** and use Android's local file picker to select a model you own or are licensed to use. The model stays in app-private storage and is SHA-256 pinned. Unsupported, malformed, truncated, or over-12 MB models are rejected. Importing the model re-renders the open photograph.
3. A learned result is accepted only if one of the fixed strengths `1,.75,.5,.25,.125` satisfies **exactly the existing V9 final-pixel safety thresholds**. The edit report explicitly says `USER_IMPORTED_ONNX_GLOBAL`, lists true damage metrics, and reports the selected strength.
4. If the model fails validation or produces no safe correction, the app keeps the original V9.3 result; it never claims AI was applied. Tap **AI · local**, then **Remove model** to return to normal V9.3 behavior.
5. **Save Copy** uses the same immutable coefficient grid and strength approved in the preview on the full-size export. Native-resolution safety is checked again. If it fails, export stops with a visible error; there is **no silent lower-resolution output or substitution**.
6. Original-to-edited press-and-hold comparison, crop, history, and other core features are preserved.

## Supported ONNX predictor ABI

Model input: name `srgb_context`, RGB `float32 [1,3,256,256]`, normalized to `[0,1]`. Prediction output: `float32 [1,12,8,1,1]` using four affine coefficients per RGB channel, eight luminance bins. Expects the architecture and affine grid operator in `research/learned_photo/model.py` on the separate research branch. This APK currently imports **global** predictors only. No experimental model should be considered deployable until training rights and independent visual review are documented.

## Verified engineering protections

- JNI ONNX runtime execution of *test-only untrained* global and spatial models
- SHA-256 model pinning; no Internet permissions needed for model inference
- Strict minimum/maximum model size; no unsanctioned weights embedded
- Whole-image rendering rather than face-only/local-only corrections
- Cancellation checks and damage-gate preservation
- Preview/export repeatability on identical source pixels
- No original bitmap mutations; full-size safety rejection never silently replaces export
- Full existing Android test suite and signed debug APK verification (must pass GitHub Actions)

## Quality caveat

Independent 16-photo Expert C research comparison: guarded learned output had normalized RGB L1 **0.09433** vs actual V9 **0.11970** (21.2% reduction), but five of sixteen individual photos **regressed**. RGB L1 is not a human preference score. The FiveK model was trained using research-restricted source/expert pairs, and model redistribution rights for this product have **not** been established. It is **not bundled**, licensed by this README, or approved for a production Android release.

**Do not merge this branch to main or advertise it as a professional-grade trained AI editor** until a rights-cleared expert-paired model shows convincing blind real-photo improvements and passes genuine on-device offline preview/export tests.
